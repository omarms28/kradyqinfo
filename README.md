# Kradyq Info Website

Static GitHub Pages-ready contact website for Omar Mohamed Samir.

## Files

- `index.html` is the public website.
- `styles.css` and `script.js` provide the polished interface and seamless animations.
- `omar-mohamed-samir.vcf` lets visitors import the profile as a phone contact.
- `CNAME` is included for GitHub Pages custom domain setup.

## GitHub Pages

Upload these files to the root of a GitHub repository, then enable Pages from the repository settings.

GitHub Pages custom domains require a valid domain name with DNS records. `kradyqinfo` is included exactly as requested, but a public domain usually needs a full name such as `kradyqinfo.com` or `info.kradyq.com`.
